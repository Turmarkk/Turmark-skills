# Douyin Jingxuan Video Script

## Core Standard

Produce 抖音精选取向的知识类中长视频内容: 可靠、有观点、听得懂、能成片、开头留得住人。

Default to Chinese. Write for spoken delivery, not an essay. If the user only asks for a small piece such as a hook, title, outline, or rewrite, deliver that piece without forcing a full script.

## First Pass

Before writing, identify these items. Infer harmless defaults; ask one concise question only when guessing would cause factual invention or a wrong stance.

| Item | Default / Decision |
|---|---|
| 赛道 | 历史、人文、文学、战争、文物、制度、社科、科普等 |
| 目标时长 | Default 5-8 minutes; use 8-12 minutes for deep history unless user specifies |
| 核心问题 | One video answers one main question |
| 观众 | Default: 0 基础但不低幼的普通抖音观众 |
| 资料状态 | User-provided sources, folder material, public knowledge, or needs research |
| 交付形态 | 逐字稿 by default; adapt to 钩子/提纲/分镜/标题/改稿/诊断 |

If source material is provided, extract before drafting:

1. Main facts that must be retained.
2. Usable conflict, reversal, or tension.
3. Claims that need uncertainty markers.
4. Material that should not be copied verbatim.
5. Visual evidence worth showing on screen.

## Quality Bar

Every output should aim for four effects:

- **获得感**: the viewer learns one real thing or gets a clearer judgment.
- **惊喜感**: familiar object plus unfamiliar angle, detail, identity, dilemma, or reversal.
- **表达力**: clear topic, coherent logic, vivid spoken language, no essay tone.
- **感染力**: connect facts to choices, emotions, costs, consequences, or modern resonance.

Avoid these low-quality patterns:

- 百科式时间线罗列 without a controlling question.
- 疑似搬运网文、百科、书籍原文、影视解说.
- 单纯朗读资料 without interpretation.
- 机械 AI 腔、营销腔、鸡汤腔、过度煽情.
- 画面单一, low-resolution material, weak subtitles, no visual logic.
- 标题夸张, fake production time, duration mismatch.
- Fabricated facts, conspiracy framing, or jokes that disrespect tragedy.

## Topic Engine

When turning a topic into a video, choose one main angle rather than listing everything.

| Dimension | Weight | Use |
|---|---:|---|
| 稀缺性 | 40% | “听过但不了解”的陌生细节 or less repeated interpretation |
| 连接性 | 30% | Connect to modern emotion, life, values, or current attention |
| 热度值 | 30% | Use platform/search/hotspot evidence if available; do not fake it |

Preferred formula:

```text
熟悉人物/事件/作品 + 陌生细节/身份/困境/反转 + 现代情绪连接 = 可讲的抖音精选选题
```

If the topic is too broad, narrow it by asking:

- 这个视频到底想推翻哪种常见印象?
- 哪个细节最适合在前 5 秒拿出来?
- 哪个矛盾能支撑 5-8 分钟而不是 30 秒?
- 观众看完会多懂一个什么判断?

## Script Workflow

Use this sequence for full scripts:

1. **Lock the promise**: Write one sentence that says what the viewer will understand by the end.
2. **Choose the opening device**: contradiction, unfamiliar detail, map, object, quote, identity reversal, or modern echo.
3. **Build the evidence chain**: arrange facts as cause, conflict, choice, consequence, interpretation.
4. **Draft in spoken paragraphs**: short paragraphs, clear pauses, terms explained immediately.
5. **Add visual cues**: mark where maps, relationships, documents, artifacts, or charts prevent confusion.
6. **Tighten the ending**: return to the opening question and leave one durable judgment.

Default structure for mid-to-long voiceover:

1. **前 5 秒**: 点题 + 悬念. Say what this is about and why it is not the usual story.
2. **5-30 秒**: 收获前置. Tell viewers what they will understand after watching.
3. **主体一**: Start from familiar context. Give only the background needed.
4. **主体二**: Tell the key story, conflict, or evidence chain.
5. **主体三**: Explain deeper cause, structure, consequence, or judgment.
6. **结尾**: Return to the opening, summarize the gain, optionally preview the next episode.

For series videos, make each episode independently understandable. End with one concise next-episode promise, and start the next episode with one concise recap.

## Opening Patterns

Adapt one pattern to the topic; do not paste mechanically.

```text
你可能听过【人物/事件】，但你未必知道，真正改变他命运的不是【大众印象】，而是【陌生细节】。
```

```text
如果只看课本，【事件】像是一串年份；但如果看地图，你会发现它其实是一场【关键矛盾】。
```

```text
很多人以为【常见判断】，但史料里更有意思的是【反常识点】。
```

```text
【热点对象】火了之后，很多人都在看热闹。但它背后的【历史对象】，比剧情更复杂。
```

Avoid stale “耗时 X 个月制作” openings unless production evidence is real and visually specific. If the user asks for a visual opening, prefer a mind map, map draft, reference list, editing timeline, artifact close-up, or source comparison.

## Spoken Style

Write like a capable narrator talking to a smart beginner:

- Use short paragraphs and natural pauses.
- Replace abstract labels with concrete nouns, actions, choices, conflicts, and consequences.
- Explain terms immediately after introducing them.
- Keep uncertainty visible: “据目前材料看”, “一种解释是”, “更稳妥的说法是”.
- Use light humor only when it does not distort facts or disrespect suffering.
- Avoid “众所周知”, “历史的车轮”, “不得不说”, “令人唏嘘的是” unless the sentence earns it.

Transformation example:

```text
Academic: 淮海战役是解放战争战略决战三大战役之一。
Spoken: 这场仗最有意思的地方，不是双方摆开阵势硬碰硬，而是一边打一边把对手一层层包进锅里。
```

## Visual Thinking

Even when only writing voiceover, include visual suggestions if they help comprehension.

| Confusion Risk | Visual Cue |
|---|---|
| 地点、路线、战场移动 | 地图、箭头、局部放大 |
| 阵营、家族、朝堂、军政关系 | 人物关系图 |
| 时间顺序关键 | 年表, but only when needed |
| 证据链或争议 | 古籍/史料截图 + 白话解释 |
| 时代气氛和物质细节 | 古画、文物、博物馆图、遗址 |
| 数量差异 | 数据图表: 人口、兵力、粮食、税、伤亡、时间跨度 |

If a viewer might be confused for 5 seconds, add a visual explanation cue.

### Rewrite / Polish

When rewriting existing copy:

1. Preserve user facts and intended stance.
2. Remove copied, encyclopedic, AI-read, or marketing-heavy phrasing.
3. Strengthen the first 30 seconds first.
4. Convert dense paragraphs into spoken beats.
5. Return the revised version, then list the 3-5 biggest changes.

## Self-Check

Before finalizing, verify:

- The output answers one core question.
- The first 5 seconds contain topic and curiosity.
- The first 30 seconds promise viewer gain.
- The middle has evidence, story, and interpretation, not just chronology.
- Historical uncertainty is qualified instead of hidden.
- The language is easy for a beginner to follow.
- Visual cues solve map, relationship, data, or chronology confusion.
- Titles match the actual content without exaggeration.
- The draft avoids encyclopedia朗读, 搬运感, 机械 AI 感, and low-quality水化.
