# 输出模板

根据用户需求，使用最小够用的模板。

默认模板字段使用中文。

## L1 选题模式

```markdown
## 候选异常

1. [异常一句话]
   - 反常点：
   - 为什么值得讲：

2. [异常一句话]
   - 反常点：
   - 为什么值得讲：

## 推荐切口

- 题目：
- 推荐原因：
- 最适合的视频方向：
```

## L2 研究模式

```markdown
## 异常

- 异常一句话：
- 类型：
- 为什么反常：

## 证据链

- 直接证据：
- 旁证：
- 未知空白：

## 对照组

- 对照对象：
- 对照意义：

## 解释分支

- 主解释：
- 备选解释：
- 低可信解释：

## 证据边界

- 文本内推理：
- 较稳判断：
- 不能断言的部分：
- 推荐句式：
  - 更稳妥的说法是……
  - 现有材料更支持……
  - 这更像是文本内部呈现出的结构，而不是已经坐实的史实结论……
  - 这里可以提出一种解释，但不能把它直接说成定论……

## 视频包装

- 一句话洞见：
- 标题 1：
- 标题 2：
- 标题 3：
- 开场钩子：
- 提纲：
```

## L3 出稿模式

```markdown
## 标题

[标题]

## 口播稿

[完整中文口播稿]
```

## 压缩规则

- 先说异常，再说人物
- 先做对照，再下结论
- 在最终结论前先交代证据边界
- 结尾要落到结构意义，不要只落在轶事趣味
- 如果没有对照组，就停在完整脚本之前
