# 选题卡模板

当用户要多个候选题、你需要比较几个方案、或者题还不够强不适合直接展开提纲时，优先使用选题卡。

默认使用中文输出。

## 标准选题卡

```markdown
## 选题卡

- 题目：
- 异常一句话：
- 异常类型：
- 为什么反直觉：
- 核心证据：
- 对照对象：
- 主解释：
- 证据边界：
- 传播角度：
- 系列潜力：
- 建议分数：
- 下一步动作：
```

## 下一步动作候选值

统一使用这几个中文值：

- `展开为提纲`
- `需要更强对照`
- `需要更强证据`
- `先作为备选`

## 批量输出收束模板

当返回 3 张以上选题卡时，最后补一个总推荐：

```markdown
## 推荐结论

- 最佳主打题：
- 为什么它最强：
- 为什么其他题作为备选：
```

## 压缩规则

每张选题卡都应该短到能快速横向比较。
不要把每一张卡都写成一篇小论文。
