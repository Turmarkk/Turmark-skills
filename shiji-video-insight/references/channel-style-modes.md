# 频道风格模式

这些模式用于“研究逻辑完成之后”的表达层。
不要让风格覆盖证据质量。

## 默认规则

如果用户没有指定风格，就选择最适合该题的最简单模式。

## 1. 快节奏好奇型

适用于：

- 异常非常锋利
- 用户想要短视频节奏
- 钩子能用一句话打出来

特点：

- 开头快
- 段落短
- 转场强依赖问题句
- 学术铺垫尽量少

最适合：

- 数字异常
- 矛盾破案
- 叙事沉默类题

## 2. 历史侦探型

适用于：

- 题目依赖冲突记载
- 用户想要“破案感”
- 对照和证据链本身就是主要看点

特点：

- 线索 -> 对照 -> 推断
- 明确指出“怪在哪里”
- 有强揭示感

最适合：

- 跨篇矛盾
- 史源传播变形
- 可疑数字

## 3. 结构洞见型

适用于：

- 真正的价值在制度、结构或因果解释
- 这个题越往上提，越有力量

特点：

- 先异常，后结构
- 节奏稳
- 结尾落到更大的规律或制度意义

最适合：

- 制度越界
- 因果倒挂
- 权力结构题

## 4. 沉浸叙事型

适用于：

- 题材场景感强
- 用户想要更长、更有气氛的口播
- 情绪和画面感有助于理解

特点：

- 更重场景描摹
- 转场更长
- 论点揭示更慢

最适合：

- 大型战争
- 剧烈转折
- 长篇溯源案例

## 快速选择规则

- 如果题目的核心是“这个数字不对劲”，优先用 `快节奏好奇型` 或 `历史侦探型`
- 如果题目的核心是“流行解释太简单”，优先用 `结构洞见型`
- 如果题目的核心是“把观众带进那个场景”，优先用 `沉浸叙事型`
