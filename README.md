# Turmark Skills

Personal Codex skills maintained by Turmark.

## Included Skills

- `history-video-script`: Writes polished Chinese history video narration scripts from topics, notes, or source material.
- `scys-url-to-markdown`: Exports authenticated `scys.com` pages into Obsidian-ready markdown with localized assets.

## Structure

Each skill lives in its own folder and includes the files needed by Codex, such as `SKILL.md`, helper scripts, agents, and references.
